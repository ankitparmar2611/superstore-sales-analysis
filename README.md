# 📊 Superstore Sales Analysis (Dynamic Dashboard)

## 📌 Objective
Analyze sales, profit, and customer trends using Python and create dynamic visualizations.

## 🛠 Tools Used
- Python
- Pandas
- Plotly
- Jupyter Notebook

## 📈 Key Features
- Dynamic charts (auto-update with data)
- Sales analysis by category, year, and month
- Top products and customers analysis
- Profit analysis by region
- Insight generation using Python

## 📊 Key Insights
- Highest sales observed in 2017
- Technology category contributes most revenue
- Top customers drive significant portion of sales
- Seasonal trends visible in monthly sales
